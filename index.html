Substrate4J

A full-featured, statically-typed Java library for Substrate-based blockchains

Interact with Polkadot, Kusama, and any Substrate chain

View on GitHub
Java 21+ · Apache 2.0

FEATURES

  • Static and type-safe APIs and types
  • Chain-specific clients generated from runtime metadata
  • Construct, sign, and submit extrinsics
  • Read and subscribe to storage & events
  • Built on the new Polkadot JSON-RPC spec
  • SR25519, Ed25519 & ECDSA — pure Java
  • Async and non-blocking
